# P2PJack

<img width="1280" height="400" alt="image-1793639979529" src="https://github.com/user-attachments/assets/7ea45b08-79ba-4978-9646-6f668f4332b2" />


Виртуальная локальная сеть для игр через интернет: аналог Hamachi или Radmin VPN, но **без своего сервера**.
Компьютеры соединяются напрямую, а игры видят друг друга так, будто стоят в одной локалке.

```
 Игрок A (10.77.12.34)                                  Игрок B (10.77.200.7)
 Minecraft ─► адаптер P2PJack ─► шифрование ─► UDP ═══ интернет ═══► UDP ─► адаптер P2PJack ─► Minecraft
```

## Как пользоваться

Всё как в Radmin VPN:

1. Запустите `P2PJack-Setup.exe` и нажмите **«Установить»**. Windows спросит права администратора: без них
   не создать сетевой адаптер. Установщик положит программу в `C:\Program Files\P2PJack`, создаст ярлыки,
   включит автозапуск и сразу откроет P2PJack.
2. Нажмите **«Новая сеть»**, придумайте название и пароль.
3. Сразу откроется приглашение: нажмите **«Скопировать»** и отправьте его другу в мессенджер.
4. Друг запускает P2PJack, нажимает **«Войти в сеть»** и вставляет приглашение целиком: название и пароль
   подставятся сами.
5. Через 10–60 секунд друг появится в списке с лаймовым квадратиком.

В окне:

| Элемент | Что значит |
|---|---|
| Клавиша питания | Включить или выключить P2PJack целиком. Светодиод в углу: лаймовый — в сети, красный — ошибка. Состояние запоминается |
| IP под именем | Ваш постоянный адрес в сети. Щелчок копирует его |
| Лаймовый квадрат | Прямое соединение, справа пинг |
| Оранжевый квадрат | Напрямую не пробиться, трафик идёт через другого участника |
| Пустой квадрат | Участник сейчас не в сети |
| Двойной щелчок по участнику | Скопировать его IP |
| Правый щелчок по участнику | Скопировать IP, открыть пинг, скопировать внешний адрес |
| Меню сети «···» | Пригласить, подключиться по адресу вручную, покинуть сеть |
| «Журнал» внизу | Что происходит под капотом: пригодится, если что-то не работает |

При запуске показывается заставка: по краю окна бежит лаймовая рамка, в центре между узлами знака летает пакет,
внизу — настоящее состояние запуска. Щелчок её пропускает, при автозапуске в трей её нет.

Крестик окна сворачивает P2PJack в трей (рядом с часами), и связь с друзьями не рвётся. Щелчок по значку
возвращает окно, правый щелчок — меню «Открыть / Включить / Выключить / Выход». Значок лаймовый, когда вы в сети.
Повторный запуск `p2pjack.exe` просто показывает уже открытое окно. Сворачивание отключается в настройках.

**Автозапуск.** P2PJack стартует при входе в Windows сразу в трей и подключается к вашим сетям — без окна UAC:
он запускается заданием «P2PJack» в Планировщике заданий с наивысшими правами. Выключается в настройках
(«Запускать вместе с Windows») или галочкой в установщике.

**Обновление** — просто запустите новый `P2PJack-Setup.exe`: он закроет работающую программу, заменит файлы
и сохранит ваши сети. **Удаление** — «Параметры → Приложения → P2PJack → Удалить» (или `uninstall.exe` в папке
программы). Удаляются только файлы P2PJack, ярлыки, автозапуск, правило брандмауэра и запись в списке программ;
сети с паролями — по вашему выбору.

Можно состоять в нескольких сетях одновременно. Сети и их участники запоминаются и при следующем запуске
подключаются сами. Настройки хранятся в `%APPDATA%\p2pjack\`.

## Minecraft

1. Хост заходит в мир → «Открыть для сети».
2. У друзей мир появляется в списке «Сетевая игра». Если не появился, выберите «Прямое подключение»
   и введите `IP_хоста:порт`; порт пишется в чате хоста при открытии мира.

Для выделенного сервера Minecraft всё то же самое, порт обычно `25565`.

## Как это работает без сервера

| Задача | Решение |
|---|---|
| Виртуальная сетевая карта | Драйвер [Wintun](https://www.wintun.net) от авторов WireGuard: адаптер `P2PJack` с IP `10.77.x.y` |
| Найти друг друга | **BitTorrent DHT**: распределённая сеть из миллионов торрент-клиентов. Каждый объявляет свой адрес под «темой», выведенной из названия сети и пароля |
| Узнать свой внешний адрес | STUN: бесплатные публичные серверы Google и Cloudflare. Через них идёт только один маленький запрос, трафик игры не идёт |
| Пройти через роутер (NAT) | UPnP (просим роутер открыть порт) и **UDP hole punching**: обе стороны одновременно стучатся друг к другу |
| Трое и больше игроков | Участники рассказывают друг другу о соседях, и сеть сама собирается в «каждый с каждым» |
| Не удалось пробиться напрямую | Трафик автоматически идёт через третьего участника, к которому оба подключены |
| Безопасность | Ключ выводится из пароля через Argon2, каждый пакет шифруется XChaCha20-Poly1305. Без пароля трафик не прочитать и не подделать |
| Тот же Wi-Fi | Участники находят друг друга широковещательным запросом в локальной сети |
| Брандмауэр Windows | Сеть P2PJack помечается как «частная», входящие подключения от `10.77.0.0/16` разрешаются (отключается в настройках) |

## Сборка

Нужен Rust (https://rustup.rs).

Установщик (программа + драйвер Wintun внутри одного файла):

```bash
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

Результат — `dist\P2PJack-Setup.exe`, его и отправляйте друзьям. Скрипт собирает `p2pjack.exe`, а затем установщик
(`installer/`), который вкладывает в себя сжатые `p2pjack.exe` и `wintun.dll` из `target\release`.

Только программа, без установщика:

```bash
cargo build --release
```

`target\release\p2pjack.exe` работает и без установки. Драйвер `wintun.dll` он скачает сам при первом включении
и положит рядом с собой (или в `%APPDATA%\p2pjack\`, если в папку программы писать нельзя). Скачанный архив
сверяется с зашитым SHA-256, подменённый файл не установится.

Иконка вшивается в exe из `assets\p2pjack.ico` (её рисует `scripts\make-icon.py`); для этого нужен `rc.exe` из
Windows SDK — без него сборка пройдёт, просто без иконки.

## Если не подключается

1. **Выключите VPN или прокси** (Happ, v2rayN, Clash, AmneziaWG и т.п.) либо добавьте `p2pjack.exe` в исключения.
   Через VPN в TUN-режиме прямое соединение и DHT не работают; P2PJack покажет предупреждение.
2. Все ли ввели **одинаковые** название сети и пароль, с учётом регистра? Надёжнее пересылать приглашение целиком.
3. Подождите минуту: поиск через DHT занимает 10–60 секунд.
4. Подключитесь вручную: друг выбирает в меню сети «Скопировать мой внешний адрес» и присылает его вам,
   вы выбираете «Подключиться по адресу…». Лучше сделать это навстречу друг другу одновременно.
5. Игра не видит хоста, хотя он в списке с лаймовым квадратиком? Проверьте, что в настройках включено
   «Пускать входящие подключения», или разрешите игру (например, `javaw.exe`) в брандмауэре Windows.
6. `ping` может не отвечать: Windows по умолчанию блокирует его. Проверяйте подключением в игре.

## Консольная версия

`p2pjack-cli.exe` — то же самое без окна, одна сеть, управление из терминала (от администратора):

```bash
p2pjack-cli.exe --network myroom --password "длинный-пароль-123" --firewall --mc-lan
```

Команды во время работы: `peers` — список участников, `add IP:ПОРТ` — подключиться вручную, `quit` — выход.
Все параметры: `p2pjack-cli.exe --help`.

## Ограничения

- Если у **обоих** игроков «симметричный» NAT (бывает в мобильном интернете и у части провайдеров), напрямую
  не соединиться. Тогда нужен третий участник с нормальным NAT: трафик пойдёт через него автоматически.
- Все, кто знает пароль, — полноправные участники сети. Давайте пароль только тем, с кем играете.
- Пароли сетей хранятся в `%APPDATA%\p2pjack\config.json` открытым текстом (как и в Radmin VPN, это нужно,
  чтобы подключаться автоматически).
- Только IPv4. Рассчитано на Windows; на Linux и macOS собирается, но там не проверялось.

## Устройство кода

| Файл | Что внутри |
|---|---|
| `src/main.rs`, `src/gui.rs` | Графический интерфейс (egui) и значок в трее |
| `src/bin/p2pjack-cli.rs` | Консольная версия |
| `src/service.rs` | Служба для интерфейса: кнопка питания, несколько сетей на одном адаптере, запоминание участников |
| `src/node.rs` | Ядро сети: участники, пробивка NAT, обмен списками соседей, ретрансляция, маршрутизация |
| `src/crypto.rs` | Argon2 → ключ сети и тема DHT; шифрование XChaCha20-Poly1305 |
| `src/discovery.rs` | BitTorrent DHT, UPnP, STUN-серверы |
| `src/config.rs` | Настройки и запомненные сети |
| `src/platform.rs` | Права администратора, брандмауэр, маршрут для Minecraft, автозапуск через Планировщик, одна копия программы |
| `src/ui_kit.rs` | Общий стиль окна программы и установщика: цвета, шрифты, кнопки, значок |
| `installer/` | Установщик и деинсталлятор `P2PJack-Setup.exe` |
| `src/proto.rs`, `src/stun.rs`, `src/tun_dev.rs` | Формат сообщений, STUN-клиент, виртуальный адаптер и скачивание Wintun |

Тесты (`cargo test`) поднимают несколько узлов на localhost без драйвера и проверяют соединение, неверный пароль,
сборку сети «каждый с каждым», ретрансляцию через третьего и разбор приглашений; тесты установщика распаковывают
программу во временную папку и проверяют, что удаление не трогает чужие файлы (`cargo test --workspace`).
Проверка STUN, DHT, скачивания Wintun и задания автозапуска в Планировщике: `cargo test -- --ignored`.

Посмотреть интерфейс без драйвера и прав администратора можно в демо-режиме с выдуманными сетями:

```bash
target\release\p2pjack.exe --demo
```
